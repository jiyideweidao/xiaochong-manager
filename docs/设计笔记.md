# 设计笔记（开发向）

实现细节和踩过的坑。用户向的说明看 [../README.md](../README.md)。

## 整体结构

一个进程搞定所有事：

```
浏览器（原生 JS）
   │  fetch /api/*
   ▼
server.py（FastAPI，唯一入口）── sulib/*（纯逻辑，不依赖 FastAPI）
   │
   ├── SQLite  data/index.db     索引、任务、重命名历史
   ├── 文件   data/thumbs/       缩略图缓存
   ├── 文件   data/nested/       压缩包嵌套解压缓存
   └── 文件   data/stage/        预览/导出暂存
```

- `server.py` 里全是路由，业务逻辑一律下沉到 `sulib`，方便单独跑脚本测
- 扫索引、生成缩略图都是**后台线程 + 任务表**（`/api/jobs` 轮询进度），不阻塞 HTTP
- 前端只有一个 `app.js`，无框架无构建，`S` 是全局状态对象

## 数据模型要点

`assets` 表一行 = 一个"可展示的东西"，可以是真实文件，也可以是压缩包里的一个成员
（`source_path` 是压缩包路径 + `inner_path` 是包内路径），唯一键就是这两者。

`kind` 决定走哪套缩略图逻辑，`group_key` / `cover_key` / `render_id` 负责
"SU 单体 + 它的贴图 + 它的效果图"绑成一组的联动预览。

## 实现要点与踩坑

1. **`data/` 是纯运行数据**，删掉只会丢缓存。但 `index.db` 里有整块硬盘的文件清单，
   所以 `.gitignore` 里必须排除它。
2. **缩略图按需生成 + 后台预取** 两条路：界面滚动到才生成（不卡），也能主动"生成缩略图"批量跑。
3. **缩略图缓存键**用源文件的路径 + mtime + 尺寸，源文件改了会自动重生成，不用手动清。
4. **分类 / 风格是从文件名里猜的**（`textutil.py`）：先剥卖家广告词（`更多免费资料`、`淘宝店铺`、
   `会员全店任下`、网址、`ID_123456` 这类），再匹配风格词典（新中式 / 现代轻奢 / 侘寂…），
   剩下的当分类名。所以"还原显示名"和"分类"是同一个函数出来的。
5. **重命名会同时改两个地方**：磁盘上的文件名 + 索引里的 `name`，两者不一致会让搜索对不上。
   每次重命名都往 `rename_history` 写一条，才能"撤销这批"。
6. **`.skp` 缩略图不需要 SketchUp**（自带解析），但**3D 看图需要** SketchUp 的 C API。
   这是两条完全独立的路，别混在一起。
7. **XCM3 是自研的预览网格格式**（`skp3d.py`），浏览器端 three.js 直接读：

   | 偏移 | 类型 | 内容 |
   | --- | --- | --- |
   | 0 | `4s` | `XCM3` 魔数 |
   | 4 | `<I` | 版本（当前 2） |
   | 8 | `<I` | 顶点数 n |
   | 12 | `<I` | 索引数 |
   | 16 | `<I` | 索引是否 32 位（顶点 > 65535 时为 1） |
   | 20 | `<6f` | 归一化包围盒 min/max |
   | 44 | `<f` | 取景尺寸（米） |
   | 48 | `<f` | **模型真实包围盒最长边（米）** —— 界面上显示"实际最长边"就靠它 |
   | 52 | `<3f`×n | 位置 |
   | … | `<3f`×n | 法线 |
   | … | `<4B`×n | 颜色 |
   | … | `<H`或`<I`×索引数 | 索引 |

   顶点统一缩放到 ±1 的盒子里（`sc = 2/size`），真实尺寸单独放在偏移 48，这样前端视角好控制、
   又不丢失"这个模型实际多大"。
8. **模型里常有飘在很远的零散几何**，直接用全包围盒取景会让主体缩成一个小点。
   所以先算一个"面积覆盖率 98% 的稳健包围盒"，只有它明显小于全包围盒时才采用。
9. **`archives.open_inner()` 是访问压缩包内成员的唯一正确入口。** 索引里的 `inner_path`
   可能是"还原后的中文名"（新扫描）也可能是"cp437 乱码名"（老索引），`open_inner` 两种都能命中；
   **不要**再用 `zipfile.ZipFile(...).open(name)` 按名字开 —— 中文名 zip 会 `KeyError`，
   表现就是"素材点开显示无法读取"。（1.1.1 修的正是这个。）
10. **打开文件统一走 `fsops.open_with_default()`**，`fsops.open_path()` 是唯一入口
    （`ops.open_asset` 也委托给它）。顺序是：
    **设置里的自定义规则 → `.skp` 找 SketchUp → 系统默认程序**。
    别在别处直接写 `os.startfile`，中文报错、文件夹走资源管理器这些都只在它里面做了一套。
11. **`open_path()` 的第二个返回值是"说明"不是"路径"**（1.1.2 改的）：
    成功时是"用哪个程序打开的"（前端取文件名显示成 `已打开 1 项（SketchUp）`），失败时是原因。
12. **查系统默认程序要查全**（`fsops._assoc_exes`）：
    `HKCU\SOFTWARE\Classes` → `HKCR`（合并视图，最权威）→ `HKLM\SOFTWARE\Classes` →
    `HKLM\SOFTWARE\Classes\Wow6432Node`（32 位程序），并且先看
    `Explorer\FileExts\.xxx\UserChoice` 的 `ProgId`。
    只查 HKLM 会漏掉 `.txt`（商店版记事本）、`.jpg`（WPS 登记在 HKCU）这类情况。
13. **注册表命令串要小心解析**：带引号时取引号里的；没引号时**按"到第一个 `.exe` 为止"切**，
    不能按空格切 —— 否则 `C:\Program Files\x.exe` 会变成 `C:\Program`。
    取到后还要 `expandvars` 展开 `%SystemRoot%`。
14. **命令是脚本宿主时要往里再走一层**：SketchUp 2026 把 `.skp` 的打开命令登记成
    `wscript.exe ...\SingleInstance\SketchUpOpen.vbs "%1"`（用来做单实例打开）。
    直接显示/使用 `wscript.exe` 既让人看不懂、拿去当默认程序还会弹脚本错误，
    所以 `_script_target()` 会读那个 `.vbs`，找出它真正启动的 exe。
15. **打包后不能用 `sys.executable -c` 去开对话框**：PyInstaller 打包后 `sys.executable`
    就是小虫管理器自己，再拿它跑 Python 代码只会又启动一遍服务 + 多开一个浏览器页，
    对话框根本不出现。所以"选择文件夹 / 选择程序"改成 PowerShell + WinForms
    （写临时 `.ps1`，`-STA -ExecutionPolicy Bypass -File` 跑），dev 和打包后行为一致。
16. **设置弹窗用页签分三块**（`openSettings()` 里的 `section#tab1/2/3` + `.tabs` + `.hidden` 切换）。
    所有控件始终留在 DOM 里、只切显示，所以按 id 绑定不受页签影响；
    "保存设置"放在页脚 `.mf` 里永远可见。
17. **退出程序是 `taskkill` 自己**（`/api/shutdown`），所以别指望在同一个进程里收尾；
    安装脚本 `InitializeSetup` 也先 `taskkill` 一遍，避免覆盖文件时被占用。

## 打包注意

- PyInstaller 用 `--onedir`：启动快、杀毒误报少，代价是目录里文件多
- 一定要 `--add-data` 带上 `static/`、`小虫.ico`、`bin/`（内嵌 7-Zip）
- `pypdfium2` 要 `--collect-all`，否则 PDF 的 dll 找不到
- uvicorn 的几个 loop / protocol 模块要写 `--hidden-import`，否则运行时才报错
- 装到 `D:\小虫管理器`（没有 D 盘才退到 Program Files）；`data` 目录用
  `onlyifdoesntexist` + `uninsneveruninstall`，卸载不删用户数据

## 自检

`tools/smoke_test.py` 对着跑着的服务走一遍：缩略图全覆盖抽查 → 压缩包内取流 → 单文件解压 →
7-Zip 读包 → 文件关联 → 3D 看图 → 前端（素材库 / 分类 / 浏览 / 多选 / 重命名 / 设置）并截图。
驱动方式是 CDP 连无头 Edge；注意 `Runtime.evaluate` 要带 `awaitPromise: true`，否则异步表达式拿到空值。
